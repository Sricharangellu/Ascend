---
title: Sales history and returns
category: Selling
summary: Look up past sales, void a mistaken sale, and process a refund with confirmation.
---

## Finding a past sale

**Sales** lists every order with filters for status, date, and a search box
across receipt number and order ID. Select a row to see the full line-item
and payment detail for that sale.

## Voiding a sale

From a sale's detail panel, **Void** cancels it. You'll be asked to confirm
before anything happens — voiding isn't reversible, so Ascend never fires it
on a single click.

## Processing a return

Go to **Returns**, find the order (searching by receipt number, order ID, or
state works), and start the refund. As with voiding, you'll see a
confirmation step before the refund is actually issued — refunds move real
money, so an accidental tap can't trigger one.

## Return items directly from a sale

If you're already looking at a sale in **Sales**, the **Return items** button
takes you straight to **Returns** with that order pre-selected, so you don't
have to search for it again.
